## Лабораторная работа №2

**Тема:** Букеты цветов (цветочная мастерская «ByKot»)

**Ссылка на группу ВК:** https://vk.ru/bykotflowers

**Что сделано:**
- Многостраничный сайт из 4 страниц: Главная, Каталог, Уход, Контакты.
- Использованы блочные и строчные элементы, ссылки, изображения, таблицы.
- CSS вынесен в отдельный файл `lab2/style.css`.
- Использованы разные виды селекторов: тега, класса, потомков, псевдоклассов.
- В таблицах использовано разное выравнивание (по левому/правому краю и по центру).


**Структура проекта:**
- `lab2/index.html` — главная
- `lab2/catalog.html` — каталог букетов
- `lab2/care.html` — уход за букетами
- `lab2/contacts.html` — контакты
- `lab2/style.css` — стили
- `lab2/images/` — изображения
